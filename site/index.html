Use from Java

Run a qualified model in Java

A marker JAR identifies and verifies model weights; it is not an inference engine. The ModelJars facade brings Integrallis Models and its Java and Rust/FFM execution backends, then resolves the qualified profile for the exact artifact.

01

Add Models and the registry

dependencies {
  implementation("org.modeljars:modeljars:0.1.0")
  runtimeOnly("org.modeljars.huggingface:ggml-org.qwen3-0.6b-gguf.q4_0:3.0.0-q4_0.1")
}
02

Resolve and verify weights

var request = ModelJar.of(
    "hf://ggml-org/Qwen3-0.6B-GGUF")
  .variant("q4_0")
  .backend("pure-java");
var registry = ModelJarRegistry.fromClasspath();
var descriptor = registry.resolve(request).orElseThrow();
var path = new ModelJarInstaller(registry)
  .install(descriptor);
03

Run inference in-process

var prompt = ChatTemplate.CHATML_NO_THINK.render(
  List.of(ChatMessage.user("Name one JVM language.")));
var options = SamplingOptions.builder()
  .temperature(0).maxTokens(32).build();

try (var backend = PureJavaBackend.load(path)) {
  var model = new RuntimeTextGenerationModel(backend);
  var answer = model.generate(prompt, options);
}

Requires Java 25 and --add-modules=jdk.incubator.vector. The qualified Rust/FFM profiles also require --enable-native-access=ALL-UNNAMED.

Apple on-device inference

Use Apple Foundation Models from Java

Integrallis Models can call the Apple Intelligence system model directly from a Java 25 process through FFM and a small Swift bridge. Apple manages the model and its updates, so it is a Models runtime option rather than a downloadable ModelJar artifact. The client implements Models' shared text-generation contract and can be passed directly to its LangChain4J and Spring AI adapters.

Apple backend guide 
implementation("com.integrallis:backend-apple:0.1.0")

try (var client = AppleFoundationModels.create()) {
  var status = client.availability();
  if (status.available()) {
    var answer = client.generate("Summarize this locally.").text();
  }
}
